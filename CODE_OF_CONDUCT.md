# Code of Conduct

Notch Police is a small project, so this is a short document.

- Treat people with respect. Disagree with ideas, not with people.
- No harassment, personal attacks, or discriminatory language — in issues, pull requests, or anywhere this project is discussed.
- Assume good faith. Most bad code is a mistake, not malice.
- Keep it on topic. This is a usage notch, not a forum.

Maintainers may edit, lock, or remove content and block participants who ignore this. If something needs a maintainer's attention, report it privately to [@theroofkashyap](https://github.com/theroofkashyap) through GitHub rather than in a public thread.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
